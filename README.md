# Natación Inclusiva Pilar

Landing page para **Natación Inclusiva Pilar**, centro especializado en natación adaptada, estimulación e hidroterapia en Pilar, Argentina.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Framer Motion
- Componentes estilo shadcn/ui
- lucide-react

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
